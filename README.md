# Тестовое задание

## Создание администратора
Команды 
- php artisan admin:create {name} {email} {password} - **задать вручную админа**
- php artisan admin:new -  **создает предопределенный логин admin/12345678**

## Архитектура

Архитектура по Laravel без разделения на Model и Entity. 
 - функции и процедуры вынесены в общие сервисы, без разделения на UseCase
 - формирования array данных вынесено в Repository, без создания отдельных Resource`s
